01 — Обо мне

Разработка, которую можно проверить

Меня зовут Алексей. Я занимаюсь веб-разработкой: собираю интерфейсы на HTML, CSS и JavaScript, пишу серверную логику на Node.js и поддерживаю проекты в продакшене. Люблю, когда код не только работает локально, но и предсказуемо доставляется до пользователей.

Этот сайт — учебный проект по практической работе «Автоматизация CI/CD для облачных веб-приложений». Каждый push в ветку main запускает GitHub Actions: проверку структуры, валидацию HTML и синтаксиса JavaScript, а затем публикацию на GitHub Pages.

  • Пишу код, который проходит автоматические проверки до попадания в main
  • Настраиваю пайплайны сборки и публикации на GitHub Actions
  • Уделяю внимание доступности и адаптивности интерфейсов
  • Работаю по принципу «маленькие изменения — частые релизы»
